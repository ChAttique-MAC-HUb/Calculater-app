# Calculator

A small, dependency-free calculator built with HTML, CSS and vanilla JavaScript.

## Features

- Add, subtract, multiply and divide, with chained operations
- Percent, sign toggle, backspace and clear
- Keyboard support: digits, `+ - * /`, `Enter`/`=`, `Backspace`, `Esc`, `%`
- Floating-point cleanup (`0.1 + 0.2` shows `0.3`)
- Divide-by-zero handling
- Light and dark mode (follows your system setting)
- Responsive layout

## Run it

Open `index.html` in your browser. No build step or install needed.

## Publish on GitHub Pages

1. Push this folder to a GitHub repository.
2. In the repo, go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Your calculator will be live at `https://<your-username>.github.io/<repo-name>/`.

## Project structure

```
index.html   page markup
style.css    styling and themes
script.js    calculator logic
```
